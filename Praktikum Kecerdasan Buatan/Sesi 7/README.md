# Mini_Csv

Dataset & Sistem Pakar Seleksi Beasiswa Kelayakan Mahasiswa IDE LPKIA (Forward Chaining & Backward Chaining).

## Akses Cepat
- **Buka Langsung di Google Colab:** [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/zysrnh/Mini_Csv/blob/main/P7C.ipynb)
- **Raw CSV 100 Data:** `https://raw.githubusercontent.com/zysrnh/Mini_Csv/main/dataset_beasiswa_lpkia_100.csv`

## Daftar File
- `P7C.ipynb` — Notebook Google Colab (otomatis terhubung Google Spreadsheet + visualisasi HTML)
- `P7C.py` — Script Python lengkap (Forward & Backward Chaining, validasi IPK, sinkron Google Spreadsheet, filter)
- `P7C.html` — Antarmuka interaktif standalone (validasi IPK, format Rp otomatis, filtering, import 100 data)
- `dataset_beasiswa_lpkia_100.csv` — Dataset 100 data mahasiswa siap import
- `dataset_beasiswa_lpkia.csv` — Dataset awal 8 data mahasiswa
